# Правила Сборки и Инвалидации Кэша

1. **Генераторы страниц**:
   - `python3 tools/build_category.py` (кирпич и карточки товара)
   - `python3 tools/build_tiles.py` (тротуарная плитка)
   - `python3 tools/build_roof.py` (кровля, фасады, штакетник)
   - `python3 tools/build_site.py` (главная и служебные страницы)
   - `python3 tools/build_search.py` (поисковый индекс `data/search.json`)

2. **Инвалидация кэша**:
   - При любых изменениях в `styles.css` или `app.js` ОБЯЗАТЕЛЬНО инкрементировать версии `STYLES_V` и `APP_V` в `tools/shell_common.py`.
   - После изменения версий кэша обязательно пересобрать все генераторы.

3. **Обязательная валидация перед сдачей задачи**:
   - `python3 tools/check_links.py` — проверка на битые ссылки, ассеты и якоря (строго 0 ошибок).
   - `python3 tools/check_texts.py` — проверка запрещенных маркетинговых формулировок.
