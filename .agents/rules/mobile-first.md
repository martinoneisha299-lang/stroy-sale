# Правила Мобильной Верстки и Адаптивности

1. **Контроль ширины экрана**:
   - Любые изменения макета обязательно тестируются на `375px` (мобильный) и `1280px` (десктоп).
   - Горизонтальный скролл недопустим: `overflow-x: hidden / clip` на корневых контейнерах, колонки сеток только через `minmax(0, 1fr)`.

2. **Первый экран смартфона**:
   - Высота первого экрана на мобильном устройстве (при вьюпорте 812px) должна быть скомпонована так, чтобы верх плиток каталога попадал в первый экран (высота шапки + hero не более 600–640px).

3. **Интерактивные элементы**:
   - Минимальный размер области нажатия (`tap target`) для кнопок, ссылок, чипов и полей — `44px` по высоте/ширине.
   - Мобильный таб-бар прикреплен с учетом safe-area: `env(safe-area-inset-bottom)`.
